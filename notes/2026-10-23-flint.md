# Flint on my Mac mini

Date: 2026-10-22 to 2026-10-23

[Flint](https://huggingface.co/RecursiveSI/flint) is an open-weight model from RecursiveSI: 40B parameters in total, with 2.5B active per token (mixture of experts). I ran a 4-bit build with Ollama on my Mac mini over two days.

## The setup

Mac mini, Apple M5 Pro, 64 GB unified memory. Flint 4-bit, served by Ollama through its OpenAI-compatible API.

## How I measured

`scripts/flint_bench.py` times any OpenAI-compatible local server using only the Python standard library. It streams one coding prompt ("Write a Python function that merges overlapping intervals, with 3 unit tests.", up to 1,024 tokens), does 1 warmup, then 3 timed runs, and prints the median of:

- time to first token
- time to the first answer token, after any reasoning
- the share of the output that was reasoning
- decode speed in tokens per second

Run it with `python3 scripts/flint_bench.py ollama` while Ollama is serving a model named `flint`.

For the coding tests I gave it a codebase of about 20K tokens and asked it to add a feature, then had it write a JSON parser from scratch.

## Results

| Test | Result |
| --- | --- |
| Short coding prompt | 115 tok/s |
| Read a 20K-token codebase | 11 s to read it, then 87 tok/s |
| Add a feature to that codebase | 40/40 tests passed |
| JSON parser from scratch | 13 failures in the first draft, all fixed in one round |
| Long coding runs | 20,000+ reasoning tokens before it wrote any code |

Memory wasn't measured in these runs.
